              Fleet Configuration Center

              Live thresholds and the default bot profile. Every account uses the same settings.

              Refresh and hunt timing
              Refresh Interval (seconds)
              refreshSeconds Applies immediately

              How often the dashboard rebuilds its data, in seconds (2 to 60). The page polls at the same pace. Without this key, website.refreshInterval from global_settings.json is used.

              Last Hunt Warn (seconds)
              lastHuntWarnSeconds Applies immediately

              An account that has sent no hunt for this long gets a warning. Accounts that are sleeping, paused, in captcha, stopped, offline or not set to hunt are not checked. Range 30 to 86400.

              Last Hunt Bad (seconds)
              lastHuntBadSeconds Applies immediately

              The same stall, at this length, makes the account a problem. It must not be below the warning value. Range 60 to 86400.

              Gateway traffic
              Inbound Warn (KB/min)
              inboundWarnKbMin Applies immediately

              Gateway traffic per account, in KB per minute, from which the account is flagged high. The Network view and the Avg inbound chip use it too. Range 10 to 10000.

              Inbound Bad (KB/min)
              inboundBadKbMin Applies immediately

              Gateway traffic per account, in KB per minute, from which the account is a problem. It must not be below the warning value. Range 50 to 20000.

              Captchas and errors
              Captchas Warn / Day
              captchaWarnPerDay Applies immediately

              Captchas seen since midnight today (local time) from which the account gets a warning and the Captchas chip turns amber. 0 warns on the first captcha. Range 0 to 100.

              Captchas Bad / Day
              captchaBadPerDay Applies immediately

              Captchas seen since midnight today from which the account is a problem and the chip turns red. It must not be below the warning value. Range 1 to 100.

              Errors Warn / Hour
              errorsWarnPerHour Applies immediately

              Console errors in the last hour from which the account gets a warning and the Errors chip turns amber. 0 warns on the first error. Range 0 to 1000.

              Errors Bad / Hour
              errorsBadPerHour Applies immediately

              Console errors in the last hour from which the account is a problem and the chip turns red. It must not be below the warning value. Range 1 to 1000.

              Accounts read these settings when they next log in. Running accounts pick them up after a bot restart.

              Dashboard server
              Listen address
              website.host Applies on dashboard restart

              The IPv4 address the dashboard listens on. 0.0.0.0 lets every device on the network open it (with a password of 8+ characters). 127.0.0.1 keeps it on this machine. Applies when the dashboard restarts.

              Port
              website.port Applies on dashboard restart

              The port of the dashboard, from 1024 to 65535. Applies when the dashboard restarts. Other devices open it at http://this-address:port/.

              Bot start and stop
              Restart the bot after a crash
              website.restartOnCrash Applies immediately

              If the bot exits with an error, the dashboard starts it again after 30 seconds, at most 3 times an hour. It never restarts the bot after Stop or after an autoStop. Applies at once.

              Start the bot with the dashboard
              website.startBotOnLaunch Applies on dashboard start

              When the dashboard starts and the bot is not running, the dashboard starts the bot. This brings everything back after a server reboot under pm2. Applies when the dashboard starts.

              Stop the bot when the dashboard stops
              website.stopBotWithDashboard Applies immediately

              When the dashboard stops (Ctrl+C or pm2 stop), the bot stops too. Off by default: the bot keeps running, and the next dashboard finds it. Applies at once.
